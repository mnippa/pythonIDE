# 01 Spielfeld-Basis v2 (ohne Tupel)

Ziele dieser Version:
- Kein Einsatz von Tupeln
- Positionen als Listen: [x, y]
- Spielerzustand als Dict
- Feld bleibt 9x9 mit Mittelblock
- Feldzustaende: Wand (1), Leer (0), Start (2), Ziel (9), Gold (7)

Hinweis:
- Der Spieler wird separat gespeichert.
- Der Startwert (2) bleibt als didaktischer Marker im Feld erhalten.
