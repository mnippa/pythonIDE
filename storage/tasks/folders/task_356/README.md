# Goldspiel Grundspiel 6x6

1:1 auf Goldspiel Schritt 3 aufgebaut (gleiche Symbolik und Steuerlogik), aber mit 6x6 Spielfeld:
- Rand komplett als Wand
- 3 verteilte innere Hindernisse
- 5 zufaellige Muenzen
- Start und Ziel

Steuerung:
- `l` links drehen
- `r` rechts drehen
- `Enter` vorwaerts
- `q` beenden
