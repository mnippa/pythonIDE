Import

import idegui as ui

Verfügbare API laut idegui.__all__:

["title", "text", "input", "number", "select", "button", "output", "get", "set", "print", "reset", "trigger", "show", "clear"]

UI-Erzeugung

FunktionSignaturBeschreibungRückgabe
title title(text="") Setzt/aktualisiert eine H3-Überschrift im idegui-Root. _Widget
text text(label="", value="") Erzeugt Text-Input (optional mit Label). _Widget mit .value
input input(label="", value="") Alias von text(). _Widget
number number(label="", value=0) Erzeugt Number-Input. Versucht Wert als float zu halten. _Widget
select select(label="", options=None, value=None) Erzeugt Dropdown mit Optionen; setzt Initialwert. _Widget
button button(label="Button") Erzeugt Button im idegui-Root. _Button
output output() Gibt Output-Objekt für Textausgaben zurück. _Output

Datenzugriff auf HTML

FunktionSignaturBeschreibungDetails
get get(name, default="") Liest Element über [data-element="name"]. Bevorzugt element.value, sonst textContent; immer String.
set set(name, value) Schreibt in Element über [data-element="name"]. Bei input/textarea/select wird value gesetzt, sonst textContent.
print print(container_name, *args, sep=" ", end="\n") Append-Ausgabe in ein Ziel-Element. Entspricht intern print_to; hängt Text an bestehenden Inhalt an.
reset reset(container_name="") Leert Inhalt eines Ziel-Elements. Bei Inputs wird value="", sonst textContent="".

Trigger und Event-Kontext

ui.trigger wird bei Trigger-Aufrufen gesetzt/aktualisiert.

ObjektAttributeBeschreibung
ui.trigger name, value Aktueller Auslöser (z.B. Button-Name und optionaler Wert). 
def berechne(trigger):
    print(trigger.name)
    print(trigger.value)

# oder direkt:
print(ui.trigger.name, ui.trigger.value)

Intern aktualisiert die Runtime Triggerdaten über idegui._refresh_trigger().

Komplette Event-Logik Vorlage

# init.py
import idegui as ui

if 'APP_STATE' not in globals():
    APP_STATE = {'counter': 0}

def plus(trigger):
    APP_STATE['counter'] += 1
    ui.set('count', str(APP_STATE['counter']))
    ui.set('last_trigger', f'{trigger.name}:{trigger.value}')

def minus(trigger):
    APP_STATE['counter'] -= 1
    ui.set('count', str(APP_STATE['counter']))
    ui.set('last_trigger', f'{trigger.name}:{trigger.value}')

ui.set('count', str(APP_STATE['counter']))
ui.set('last_trigger', '-')
<!-- index.html -->
<button data-function="plus" name="plus" value="+1">+</button>
<button data-function="minus" name="minus" value="-1">-</button>
<div data-element="count">0</div>
<div data-element="last_trigger">-</div>
