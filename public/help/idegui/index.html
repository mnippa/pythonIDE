Was ist idegui?

idegui verbindet Python-Code in init.py mit HTML-Elementen in index.html. Die Oberfläche wird in #gui-container gerendert, Python läuft über Pyodide im Browser.

  • HTML/CSS definieren das UI
  • Python steuert Logik und Interaktionen
  • Kein eigenes JavaScript in Projekt-HTML nötig

Die zwei Logik-Modi

1) Direkte Python-Logik

Code läuft bei Run einmal durch und schreibt Ergebnisse mit ui.set() ins HTML.

2) Event-Logik

Buttons/Forms mit data-function="funktionsname" rufen gezielt Python-Funktionen auf; data-run="true" startet den kompletten Run.

Python-Handler-Signatur: def meine_funktion(trigger):

Dateien pro Webprojekt

  • index.html – Struktur und Elemente mit data-element
  • style.css – Styling
  • init.py – Python-Logik mit import idegui as ui

Bei HTML-/Mixed-Templates werden diese Dateien automatisch angelegt.
