idegui Quickstart

Schneller Start für Python + HTML Projekte

Übersicht Quickstart Vollständige Codereferenz

Minimaler Event-Handler

<!-- index.html -->
<input data-element="name" value="Markus">
<button data-run-python="true" data-run-name="say_hello">Hallo</button>
<div data-element="msg">-</div>
# init.py
import idegui as ui

def say_hello(trigger):
    name = ui.get('name')
    ui.set('msg', f'Hallo {name}!')

Direkte Logik (ohne Trigger)

# init.py
import idegui as ui

zahl1 = 12
zahl2 = 30
ui.set('summe', str(zahl1 + zahl2))

Best Practices

  • Nutze globale Dicts für Zustand (z.B. APP_STATE).
  • Validiere Eingaben aus ui.get() mit try/except.
  • Schreibe alle sichtbaren Ergebnisse mit ui.set() in HTML.
  • Verwende keine zusätzlichen JavaScript-Skripte in Projekt-HTML.
